# Source and ownership provenance

This public repository originated as a scanner-only source snapshot derived from PatchWRK's
private development repository. It intentionally does not contain the complete
private Git history. The original repository and all reachable history remain intact;
no history rewriting or ownership transfer occurred in preparing this export.

The existing MIT copyright holder and package author remain **Jovan Simon**.
Historical development commits include the author identity **savedbydeals** as well
as Jovan Simon; credit is not reassigned to a newly invented author. Personal commit
email addresses and unrelated private operations history are not required to run this
snapshot and are not copied into this distribution. This is an explicit selective
export, not a claim of new authorship or concealed historical ownership.

`PUBLIC_FILES.json` records each exported file's hash plus the private source's base
commit and an explicit dirty-worktree indicator. The base commit alone does not
identify uncommitted source changes; the file hashes define that initial snapshot.
Subsequent reviewed commits may change
files; the manifest is historical evidence, not a current-tree checksum manifest.
No `.git` directory or public commit history is generated by the exporter.

The founder approved transparent legitimate attribution. Publication does not
authorize rewriting ownership records or removing required notices.
The MIT license is copied byte-for-byte. Bundled TypeScript/semver retain their original
licenses and notices in the separately prepared offline package. Repository branding
is cosmetic and does not change legal ownership or existing attribution.
